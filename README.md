## Excite Truck (Wii) Decompilation Project
This is a work-in-progress decompilation of the Nintendo Wii game Excite Truck.

This project is for educational and research purposes only.

### Credits

- Revolution SDK sources and headers (`include/revolution`, `include/MSL`, `include/decomp`, `src/revolution`) are adapted from [ogws](https://github.com/kiwi515/ogws), the Wii Sports decompilation (CC0). Excite Truck ships SDK builds from the same 2006 release.
- Built on [dtk-template](https://github.com/encounter/dtk-template), [decomp-toolkit](https://github.com/encounter/decomp-toolkit) and [objdiff](https://github.com/encounter/objdiff).
